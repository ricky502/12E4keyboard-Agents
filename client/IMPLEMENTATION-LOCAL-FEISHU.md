# Agentpad 最终实施说明：本机飞书模式

## 目标

键盘插在你的当前电脑时，控制本机 Codex、VSCode Claude 和本机已登录的飞书客户端；飞书云把消息送到/送回 Mac Mini 上原有 Agent。

```text
键盘 USB → 当前 Mac 的 Agentpad → 当前 Mac 的飞书客户端 ↔ 飞书云 ↔ Mac Mini 原有 Agent
```

Mac Mini 不需要安装任何 Agentpad 服务，不开放端口，不与当前 Mac 建立任何网络连接。

## 8 个 Agent 键

| 位置 | 键 | 本机动作 |
|---|---|---|
| 第一排 | 探春、黛玉、湘云、香菱 | 打开本机相应飞书会话 |
| 第二排 | 莺儿、Codex、VSCode Claude、宝钗 | 莺儿显示本机飞书可见状态；Codex/Claude 打开本机应用；宝钗打开本机飞书会话 |
| 第三排 | 语音、批准、拒绝、新任务 | 作用于当前选中 Agent；飞书 Agent 仅打开/聚焦本机对应会话，不后台代发或点击卡片 |

## 旋钮和旧功能

- E1：保留原缩放；E2：保留原播放/暂停相关功能。
- E3：本机 Codex 的思考深度；E4：本机 Codex 的模型切换。
- 原音量 ± 是两个普通按键，不是旋钮；8 Agent + 4 功能键已经占满 12 个主键，音量将留给后续系统层。
- 四个旋钮的物理左右顺序在刷入新固件后，通过转动并观察事件一次性确认。

## 状态灯

状态只从当前 Mac 采集：

- 本机 Codex/VSCode Claude：本机命令与应用状态；
- 飞书 Agent：本机飞书窗口的 OCR，识别当前会话、`Generating`、批准卡片、错误文案；
- 不读取 Mini 的文件、端口、数据库或网络。

OCR 仅截取飞书窗口、只在当前 Mac 识别文字。首次启用需要给本机客户端“屏幕录制”权限；默认关闭。
