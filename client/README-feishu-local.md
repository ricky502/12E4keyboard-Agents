# 本机飞书模式

这是 Agentpad 的唯一远端通道：键盘只控制本机，远端 Agent 继续按原样通过飞书云与本机飞书客户端通信。**不连接、不配置、不改动 Mac Mini。**

```text
键盘 USB → 本机 Agentpad → 本机飞书客户端 ↔ 飞书云 ↔ 原有 Agent
```

## 本机可做的事

- 选择键：直接打开本机对应的飞书会话；
- 语音键：打开当前会话，录音/转写仍由飞书客户端完成；
- 状态灯：从本机飞书窗口的“生成中”、批准按钮、错误提示和活动会话读取；
- 本机 Codex、VSCode Claude：继续由本机客户端直接控制。

“新任务、批准、拒绝”也只会打开并聚焦对应的本机飞书会话；不会替你在后台发送文本或点击批准卡片。这样每个实际动作都保持可见，并仍然只发生在本机飞书。

`feishu_local_ocr.swift` 只截取飞书自身窗口并在本机完成 OCR，不发送消息、不读取 Mini 文件或端口。首次运行需要在 macOS「隐私与安全性 → 屏幕录制」允许运行该客户端；辅助功能采集器仅作为会话名称的回退方案。

未授权时，采集器会明确返回权限错误，不会将空数据误判为 Agent 空闲。

安装后，将 `~/Library/AgentpadClient/config.json` 的 `feishu_local_observer` 改为 `true`，重启客户端即可启用。默认关闭，因此未授予辅助功能权限时不会反复尝试读取飞书。

## 已知边界

飞书桌面客户端没有官方的本地聊天事件 API，因此此版本的状态来自本机可见界面。它对当前打开的 Agent 会话最准确；其他未打开会话只能按可见预览/未读信息显示。新任务、批准、拒绝仍先以“打开相应本机飞书会话/卡片”为主，避免后台替你发送或批准内容。
