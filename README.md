# 12E4keyboard-Agents

将 CXT Studio 12E4 客制化小键盘改造成 Agent 工作台：用实体按键切换 Agent、用灯光展示任务状态，并在 macOS 本机接入飞书、Codex 和 VS Code Claude 工作流。

## 最新功能：v14 原生低延迟按键与旋钮

- v13 将语音与批准改为固件原生 Option / Enter，消除了软件模拟按键的数秒等待。
- v14 将四个旋钮的旋转动作改为固件原生 USB 键：1 号屏幕亮度、2 号快退/快进、3 号系统音量、4 号文字缩放或网页视频倍速。
- 4 号旋钮可在“文字大小”和“播放速度”之间切换；播放速度模式支持 YouTube、B 站网页视频，单格调整 0.25×，范围 0.25×–3×。
- 旋转不再经过 Raw HID、本地 HTTP 和脚本转发；播放控制也不逐格查询 Chrome 当前网址。
- 全部处理都在本机完成，不连接远程 Agent 主机，也不会读取或上传视频内容。

详细版本记录见 [`CHANGELOG.md`](CHANGELOG.md)，浏览器适配器安装方法见 [`browser/README.md`](browser/README.md)。

## 项目组成

- `firmware-package/`：12E4 的 Agentpad 固件、刷机脚本、USB/HID 协议与恢复原厂固件说明。
- `client/`：macOS 常驻客户端，负责键盘灯效、按键/旋钮命令、飞书状态监听，以及 Codex、Claude 的本机适配。
- `今日开发报告-2026-08-24.md`：当天完成内容与可用范围。

## 当前可用功能

- 8 个 Agent 槽位及状态灯：待机、工作、完成、等待输入、异常；当前选中的工作中 Agent 使用原状态色全亮常亮，其他工作槽位同色降亮呼吸，其他空闲槽位熄灭。
- 飞书群状态消息的本机实时监听；不需要与远程 Agent 主机建立网络连接。
- 4 个功能键：语音、批准、拒绝（`/stop` 后回车）、新任务；底部灯光随当前 Agent 状态提示。4 个旋钮由本机客户端处理，其中 4 号旋钮支持文字缩放/网页视频倍速双模式。
- macOS 开机自启、USB/HID 连接自检与断线重连。

## 快速开始

1. 先阅读 `firmware-package/README-Codex.md` 并按说明刷入固件。
2. 再阅读 `client/README.md`，安装本机常驻客户端。
3. 飞书 App Secret 仅存 macOS 钥匙串，不写入配置文件或版本库。

## 安全说明

本仓库不包含飞书 App Secret、访问令牌、macOS 钥匙串内容、个人飞书聊天记录或个人键位备份。请以示例配置为基础，在自己的设备上完成配置。
